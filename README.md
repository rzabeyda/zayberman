# Zayberman — бот записи на консультации (@zaybermanbot)

- Кнопки: 📝 Запись · 📋 Брони · 💬 Связаться, для админа — ⚙️ Админка
- Консультация 60 мин, перерыв 30 мин, начало 08:00–18:00 (по Таллину, шаг 30 мин)
- Клиенты видят время по МСК, админ — по Таллину (`TZ_ADMIN` в config.py)
- Бронь держится 2 ч до оплаты; оплата скрином (подтверждение админом) или USDT/GRAM с кодом в комментарии (автопроверка через toncenter)
- Напоминания за 24 ч и 1 ч

Сервер: `/root/zayberman`, сервис `zayberman_bot.service`, токен в `.env`.
